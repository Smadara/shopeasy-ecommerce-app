# ShopEasy - Full-Stack E-commerce Website

A full-stack e-commerce website built with **React, Node.js/Express, and MySQL**.

## Features

* User registration and login with JWT authentication
* Browse, search, and view products
* Shopping cart and checkout
* Place and view orders
* Admin dashboard for managing products and orders

## Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MySQL
* **Authentication:** JWT
* **Tools:** Git, GitHub, XAMPP

## Setup

```bash
cd backend
npm install
npm run dev
```

Create the MySQL database and configure the `.env` file.

For the frontend:

```bash
cd frontend
npm install
npm start
```

The backend runs on `http://localhost:5000` and the frontend runs on `http://localhost:3000`.
